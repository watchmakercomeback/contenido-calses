# Exercises Class 1

## Letters that Repeat

This is a raw JavaScript (vanilla) file that takes a word and returns a dictionary with the number of repeated letters in descending order.

To run the file, go to the project directory and run the following command in the terminal:

```bash
npm run words
```

## Rule Engine with Only Types in TypeScript

A type-level engine that implements logical rules using only TypeScript types.

You initialize an object with different characteristics (a user) and define the basic structure of the object. Then, the type system applies each rule and determines whether the object is VALID or INVALID, without executing any JavaScript code at runtime.
